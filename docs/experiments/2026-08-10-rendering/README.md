# 足立レイ レンダリング聴感評価 2026-08-10

固定コーパス`utautts-ja-core-v1`の12文と足立レイver3.5.0を使い、WORLD hybrid系レンダラを1名でブラインドAB比較した。イントネーション強度は0.6。

## 結果

| 比較 | 左側の選好 | 右側の選好 | 同程度 |
| --- | ---: | ---: | ---: |
| 従来hybrid vs 全CV固定部復元 | 従来 2 | 全復元 10 | 0 |
| 全CV固定部復元 vs balanced | 全復元 0 | balanced 6 | 6 |
| 従来hybrid vs balanced | 従来 0 | balanced 11 | 1 |

全CV固定部復元は発音の歯抜けを大幅に減らした一方、固定部の周期成分まで直接波形へ戻すため、ガラガラした粗いケロケロ声が目立った。balanced方式は復元をCV aliasの発音開始前からノート境界直後8msまで、最大85%に制限した。

最終比較では、多少の粗さより音素脱落の方が自然さを大きく損なった。たとえば「この声は自然に聞こえますか？」が従来版では「このおえわしぜんにきこえやすか？」のように聞こえ、balanced方式が選ばれた。したがって足立レイでは、まず文章を正しく聞き取れることを自然さの前提とし、balanced方式を推奨する。

評価者1名・単一音源の結果なので、他のボイスバンクへの一般化は行わない。

## 参考: 韻律モデル

同じ12文で従来hybridと保守的な韻律モデルv3を比較した結果は、従来1、韻律モデル0、同程度11だった。足立レイでは音源固有の歯抜け感が支配的で、保守的な韻律差はほぼ識別できなかった。
