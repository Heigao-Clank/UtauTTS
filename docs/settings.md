# 設定

メニューバーの「設定」→「設定...」ではこれから追加する文章カードの初期値とアプリ全体の動作を変更できます。「保存」を押すと反映されて次回起動時にも引き継がれます。

音声合成ページの値は保存したときに選択している文章カードにも反映されます。ただしデフォルト音源は新しく追加するカードにだけ使われます。すでに作成したほかのカードはそのままです。

## 音声合成

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| デフォルト音源 | 自動（一覧の先頭） | 新しい文章カードで使うボイスバンク。音源を固定したい場合は名前を選びます |
| デフォルト抑揚モデル | `frame-intonation-v8` | 自動イントネーションに使うモデル。「なし」では原音のピッチを維持します |
| デフォルトRenderer | `openutau-worldline-r-faithful` | 原音の長さと高さを変え、接続してWAVにする方式 |
| デフォルトモーラ長 | 120 ms | モデルまたは手動編集で長さを指定していないモーラの長さ |
| デフォルト休止長 | 180 ms | 句読点などに割り当てる休止時間 |
| デフォルトの文頭の長さ | 自動 | 最初の原音で確保する先行発声。先頭が欠ける音源では長く、余計なノイズを拾う音源では短くします |
| 手動ピッチ変更の許可 | 有効 | モデルと手動編集によるピッチ変更を合成音声へ適用します |

文頭の長さを「自動」にすると最初の原音の`oto.ini`にある先行発声を基準にRendererが余白を決めます。0〜300 msの固定値も指定できます。文章カード右側にも同じ項目があるので音源や文章ごとに変えても大丈夫です。

Rendererごとの違いは[モデル／Rendererプラグイン](plugins.md)にあります。各カードの原音形式、音高、抑揚などは[GUIの使い方](gui.md#音声合成の設定)を参照してください。

## 書き出し

WAVを保存するとき同じ場所へ同名の付随ファイルも保存できます。どちらも初期状態では無効です。

| 項目 | 内容 |
| --- | --- |
| WAVと一緒にテキストファイルを保存する | 入力した文章を`.txt`で保存します |
| テキストファイルの文字コード | UTF-8またはShift_JIS（CP932）を選びます。LABには影響しません |
| WAVと一緒に.labファイルを保存する | 音素と開始・終了時刻をHTK形式の`.lab`で保存します |

例えば`001.wav`を書き出すと設定に応じて`001.txt`と`001.lab`も作られます。一括WAV保存とexo出力でも同じです。PSDToolKitなどへ渡すときはWAV・TXT・LABのファイル名を変えずに使います。

LABには1秒を10,000,000とする整数時刻と音素名を1行ずつ記録します。文頭余白と先行発声は実際の合成結果に合わせていますが音素境界はUTAU原音と合成時刻から求めた推定値です。

## 表示

- テーマはライトとダークから選べます。
- 表示言語は日本語、English、中文に対応しています。
- 「アップデートの確認と通知を行う」が有効なら起動時にGitHub Releasesを確認します。新しい版がある場合だけ通知して更新しない版は次のリリースまで非表示にできます。
- 開発者モードを有効にすると「設定」メニューへ「抑揚の教師データ生成」が追加されます。普通に音声を作るだけなら必要ありません。

アップデートでは現在の`voice`ディレクトリとアプリ設定を残したまま配布ファイルを更新してUtauTTSを再起動します。自動更新に失敗した場合はリリースページが開きます。

## ログ

「成功時にログを閉じる」が有効なら合成に成功したあと音声合成ログを自動で閉じます。無効にすると成功時の処理内容もそのまま確認できます。エラーが起きた場合は設定に関係なくログが残ります。

## ショートカット

変更したい欄を選んで割り当てるキーを押します。`Backspace`で割り当てを外せます。同じキーを複数の操作へ割り当てることはできません。

初期値は[GUIの使い方](gui.md#標準ショートカット)にまとめています。`Ctrl+Z`と`Ctrl+Y`で戻せるのはイントネーションとモーラ長の編集だけです。文章やカードの追加・削除・並べ替えは対象に含みません。

## 辞書設定

「設定」→「辞書設定...」は設定ウィンドウとは別に開きます。表記と読みの組をアプリ全体へ保存して入力済みの文章も保存後に再解析します。詳しくは[辞書設定](dictionary.md)を参照してください。

## プロジェクトに保存されるもの

`.utautts`には文章カードの順序、文章、音源、モデル、Renderer、原音形式、音高、音源タイプ、各種時間、イントネーション、ピッチとモーラ長の編集結果が保存されます。

テーマ、言語、デフォルト値、書き出し設定、ショートカット、辞書はアプリ全体の設定なのでプロジェクトには入りません。別のPCで同じプロジェクトを開くなら使用しているボイスバンク、モデル、Rendererもその環境に用意してください。
