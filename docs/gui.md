# GUIの使い方

## 起動と音源の追加

配布ZIPを展開して `utautts.exe` を起動します。追加のUTAUボイスバンクは、実行ファイルと同じ階層の `voice` ディレクトリに音源ごとのフォルダを作って配置してください。

メニューバーの「ファイル」→「音源を再読込」を選ぶと、配置した音源が一覧へ反映されます。音源フォルダには、少なくとも利用する発音の `oto.ini` が必要です。

音源を追加・整理するときは、メニューバーの「ファイル」→「音源フォルダを開く」から配置先を直接開けます。「設定」→「設定...」→「音声合成」の「デフォルト音源」で、新しい文章カードに最初から選択する音源を指定できます。「自動（一覧の先頭）」にすると従来どおりです。

## 文章の入力

左側のカードへ、音声化したい文章を入力します。カードは次の操作に対応しています。

- 右下の「追加」ボタン、または `Ctrl+D` でカードを追加します。追加したカードが選択され、入力欄にフォーカスされます。
- カード右側の「⋮」メニューから、カードを上下へ移動したり削除したりできます。
- 音源画像をドラッグして、カードを並べ替えます。
- `Delete` で選択中のカードを削除します。ショートカット設定で割り当てを変更できます。

カードを並べ替えたり削除したりすると、プロジェクトは未保存状態になります。

## 音声合成の設定

右側の設定欄で、選択中の文章ごとに次の項目を変更できます。

- 音源: 使用するボイスバンク
- 原音形式: `自動`（音源のVC/VCV収録比から選択）、`従来互換`（v0.0.9の選択・接続）、`CVVC明瞭化`（CVVC優先・sequential接続・VC音量35%）、`VCV優先`、`CVVC優先`、`単独音のみ`。通常は`自動`を使用します。
- 抑揚モデル: 自動イントネーションや自動モーラ長に使うモデル。`frame-intonation-v8` はフレーム単位のイントネーション、`prosody-multitask-v1` はv8系のイントネーションに加えてモーラ長を予測します。
- Renderer: 原音の接続とピッチ処理の方式。`waveform` は明瞭度を優先する基準、OpenUTAU Classic faithful系はモデルのピッチを適用する方式です。
- 音高: `prefix.map` で使用する音階
- 抑揚: 自動イントネーションの強さ。0で自動イントネーションを無効にし、2で最大強度になります。
- モーラ長: 個々のモーラに自動値がない場合に使う基本長
- 休止長: 句読点などの休止時間

解析が完了すると、合成前に自動イントネーションと自動モーラ長がピッチグラフへ反映されます。必要に応じて、合成前に手動で調整できます。

## イントネーションとモーラ長の編集

画面下部のグラフでは、読みの各モーラを確認できます。

- 点を上下へドラッグすると、そのモーラの手動ピッチ補正を変更します。
- 点の位置にある縦線を左右へドラッグすると、モーラの境界と長さを変更します。
- `Shift` を押しながら縦線を動かすと、そのモーラ以降の縦線も同じ距離だけ追従します。
- グラフ下部のモーラ長表示をダブルクリックすると、そのモーラと両隣のモーラを基本長へ戻します。
- 文章を変更すると、読みと編集点は新しい解析結果に合わせて作り直されます。

モーラが多い文章では、グラフ下部の横スクロールバーで移動できます。句読点などの休止は、ピッチ・モーラ長の編集点として表示されません。

## 再生と保存

メニューバーの「再生」から、次を選べます。

- 選択中のテキストを再生
- 全テキストを再生
- 選択中のテキストより先をすべて再生
- もう一度再生（キャッシュ済み音声）

「ファイル」→「WAVを保存...」で選択中の音声を保存できます。「WAVをすべて保存...」では、文章が入力されているカードをまとめて合成して保存します。

プロジェクトは「ファイル」→「プロジェクトを保存...」で `.utautts` ファイルへ保存し、「プロジェクトを開く...」で読み込みます。辞書設定はプロジェクトには含まれず、アプリケーション全体の設定として保存されます。

## exo出力とドラッグ＆ドロップ

「ファイル」→「選択テキストをexoに出力...」または「全テキストをexoに出力...」を選びます。最初にフレームレート指定ダイアログが開くので、AviUtlプロジェクトのフレームレートに合わせて指定してください。次にWAVの保存先ディレクトリを指定すると、合成が始まります。

合成が終わると、指定したディレクトリに文章ごとの `001_...wav` と、それらを1レイヤーに順に配置した `utautts.exo`（AviUtl拡張編集のオブジェクトファイル）が書き出されます。「exoをドラッグ」ウィンドウが表示されるので、中央の領域をドラッグしてAviUtlの拡張編集上で離してください。


この機能は編集ソフトへWAVファイルを通常のファイルドラッグとして渡します。編集ソフト側のバージョンや設定によって、受け入れ位置・動作が変わる場合があります。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

「設定」→「設定...」のショートカット欄で変更できます。同じキーを複数の操作へ割り当てることはできません。
