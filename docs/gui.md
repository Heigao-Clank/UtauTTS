# GUIの使い方

初めて試すなら同梱音源を選んだまま左側の文章欄へ文を入力して`Ctrl+Enter`を押します。解析が終わるとイントネーションとモーラ長が下のグラフへ表示されて、その設定で合成と再生が始まります。気になるところだけグラフで直して「ファイル」→「WAVを保存...」から保存。だいたいこの流れです。

## 起動と音源の追加

配布ZIPを展開してWindowsでは`utautts.exe`、Linuxでは`./utautts`を起動します。Linuxで必要なQt実行環境は[インストール](installation.md)を参照してください。UTAUボイスバンクを追加するときは実行ファイルと同じ階層の`voice`ディレクトリへ音源ごとのフォルダを作って配置します。

メニューバーの「ファイル」→「音源を再読込」を選ぶと配置した音源が一覧へ反映されます。音源フォルダには少なくとも利用する発音の`oto.ini`が必要です。

音源を追加・整理するときはメニューバーの「ファイル」→「音源フォルダを開く」から配置先を直接開けます。「設定」→「設定...」→「音声合成」にある「デフォルト音源」では新しい文章カードへ最初から設定する音源を指定できます。「自動（一覧の先頭）」なら従来どおりです。

## 文章の入力

左側のカードへ音声化したい文章を入力します。カードでできる操作は次のとおりです。

- 右下の「追加」ボタンか`Ctrl+D`でカードを追加します。追加したカードが選択されて入力欄にフォーカスされます。
- カード右側の「⋮」メニューからカードを上下へ移動したり削除したりできます。
- 音源画像をドラッグするとカードを並べ替えられます。
- `Delete`で選択中のカードを削除します。割り当てはショートカット設定で変更できます。

カードを並べ替えたり削除したりするとプロジェクトは未保存状態になります。

## 音声合成の設定

右側の設定欄で選択中の文章ごとに次の項目を変更できます。

- 音源: 使用するボイスバンク
- 原音形式: `自動`（音源のVC/VCV収録比から選択）、`従来互換`（v0.0.9の選択・接続）、`CVVC明瞭化`（CVVC優先・sequential接続・VC音量35%）、`VCV優先`、`CVVC優先`、`単独音のみ`。通常は`自動`を使用します。
- 抑揚モデル: 自動イントネーションや自動モーラ長に使うモデル。`frame-intonation-v8`はフレーム単位のイントネーション、`prosody-multitask-v1`はv8系のイントネーションに加えてモーラ長を予測します。
- Renderer: 原音の接続とピッチ処理の方式。通常は既定の`OpenUTAU WORLDLINE-R faithful`を使います。`waveform`は原音の明瞭度を確認するときの比較基準、`OpenUTAU Classic faithful`は原音ごとのWorldline再合成と5点包絡線で接続する方式です。
- 音高: `prefix.map`で使用する音階
- 抑揚: 自動イントネーションの強さ。0で自動イントネーションを無効にし、2で最大強度になります。
- モーラ長: 個々のモーラに自動値がない場合に使う基本長
- 休止長: 句読点などの休止時間
- 文頭の長さ: 最初の原音に確保する先行発声。通常は`自動`を使い、先頭の欠けや余計なノイズがある音源だけ手動で調整します

解析が終わると合成前に自動イントネーションと自動モーラ長がピッチグラフへ反映されます。気になるところがあればそのまま手動で調整できます。

開発者モードでは確認した手動調整を教師データとして書き出す専用画面を利用できます。文章セットは10文の基本確認セットかJSUT BASIC5000から選んだ50文セットです。集めたデータから個人用の補正モデルを作る場合は[手動調整から抑揚モデルを作る](prosody-model-training.md)を参照してください。

## イントネーションとモーラ長の編集

画面下部のグラフでは読みの各モーラを確認できます。

- 点を上下へドラッグするとそのモーラの手動ピッチ補正が変わります。
- 点の位置にある縦線を左右へドラッグするとモーラの境界と長さが変わります。
- `Shift`を押しながら縦線を動かすとそのモーラ以降の縦線も同じ距離だけ動きます。
- グラフ下部のモーラ長表示をダブルクリックするとそのモーラと両隣のモーラが基本長へ戻ります。
- 抑揚とモーラ長の編集は元に戻す・やり直す操作の対象です。
- 文章を変更すると読みと編集点は新しい解析結果に合わせて作り直されます。

モーラが多い文章ではグラフ下部の横スクロールバーで移動できます。句読点などの休止はピッチ・モーラ長の編集点には表示されません。

## 再生と保存

メニューバーの「再生」から次を選べます。

- 選択中のテキストを再生
- 全テキストを再生
- 選択中のテキストより先をすべて再生
- もう一度再生（キャッシュ済み音声）

「ファイル」→「WAVを保存...」で選択中の音声を保存できます。「WAVをすべて保存...」なら文章が入力されているカードをまとめて合成して保存します。

「設定」→「設定...」→「書き出し」ではWAVと同じ場所へ同名の付随ファイルを保存できます。

- `.txt`: カードへ入力した文章。UTF-8またはShift_JIS（CP932）を選択できます。
- `.lab`: 音素とその開始・終了時刻。時刻は1秒を10,000,000とするHTK形式で、PSDToolKitなどのリップシンクに利用できます。

例えば`voice.wav`を保存すると設定に応じて`voice.txt`と`voice.lab`も作られます。LABの時刻にはRendererが確定した文頭余白と先行発声を反映しますが、音素境界はUTAU原音と合成時刻から求めた推定値です。

プロジェクトは「ファイル」→「プロジェクトを保存...」で`.utautts`ファイルへ保存し「プロジェクトを開く...」で読み込みます。辞書はプロジェクトには含まれずアプリケーション全体の設定として保存されます。

## exo出力とドラッグ＆ドロップ

「ファイル」→「選択テキストをexoに出力...」か「全テキストをexoに出力...」を選びます。最初にフレームレート指定ダイアログが開くのでAviUtlプロジェクトのフレームレートに合わせて指定してください。次にWAVの保存先ディレクトリを指定すると合成が始まります。

合成が終わると指定したディレクトリへ文章ごとの`001_...wav`と、それらを1レイヤーに順番に置いた`utautts.exo`（AviUtl拡張編集のオブジェクトファイル）が書き出されます。付随ファイルを有効にしている場合は各WAVと同名のTXT／LABも保存されます。「exoをドラッグ」ウィンドウが表示されたら中央の領域をドラッグしてAviUtlの拡張編集上で離してください。


この機能は編集ソフトへWAVファイルを普通のファイルドラッグとして渡します。受け入れ位置や動作は編集ソフト側のバージョンと設定によって変わる場合があります。

## 標準ショートカット

| 操作 | 初期ショートカット |
| --- | --- |
| 元に戻す | `Ctrl+Z` |
| やり直す | `Ctrl+Y` |
| 音声合成 | `Ctrl+Enter` |
| プロジェクト保存 | `Ctrl+S` |
| ボイスバンク再読み込み | `Ctrl+O` |
| テキスト追加 | `Ctrl+D` |
| テキスト削除 | `Delete` |

「設定」→「設定...」のショートカット欄で変更できます。同じキーを複数の操作へ割り当てることはできません。

設定画面の全項目とアプリ設定／プロジェクト設定の違いは[設定](settings.md)にまとめています。

## アップデートと診断情報

アップデート確認を有効にしている場合は起動時にGitHub Releasesを確認して新しい版があれば通知します。通知からそのまま更新するかリリースページを開けます。更新しても現在のボイスバンクとアプリ設定は残ります。

起動や合成の問題を報告するときは「ヘルプ」→「診断情報を書き出す...」でJSONを保存してください。OS、アプリの設定、利用可能な音源・モデル・Renderer、ログが入ります。入力した文章、音声、ボイスバンクの絶対パスは含みません。このファイルとエラーの再現手順があると原因を追いやすくなります。
