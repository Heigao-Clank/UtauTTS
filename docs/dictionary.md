# 辞書設定

GUIの「設定」→「辞書設定...」から、文章中の表記と読みの対応を登録できます。登録した辞書は、文章の読み解析と音声合成の両方で使用されます。

## 登録方法

1. 「表記」に、文章中で置き換えたい文字列を入力します。
2. 「読み」に、読み上げたいひらがなまたはカタカナを入力します。
3. 「保存」を押します。

### 例

| 表記 | 読み |
| --- | --- |
| `UtauTTS` | `うたうてぃーてぃーえす` |

保存すると辞書はアプリケーション設定へ保存され、次回起動時も使用されます。保存後、入力済みの文章は現在の辞書で再解析されます。

## 注意点

- 辞書はプロジェクトファイル（`.utautts`）には含まれません。プロジェクトとは別に、アプリケーション全体で共有されます。
- 表記は文章中の一致箇所を置き換えます。単語の境界は判定しないため、登録内容によっては単語の一部にも適用されます。
- 表記が重なる場合は、より長い表記が優先されます。
- 読みには、発音させたいひらがなまたはカタカナを入力してください。空欄の行は保存時に無視されます。
