# v9抑揚モデル計画 / v9.1改善

## 目的

v9は、v8のように10msごとのF0を直接学習するのではなく、Open JTalkが与える日本語アクセントの基準曲線に対する、話者らしい句単位の補正を学習する。音声の接続とピッチ適用は、当面 `openutau-classic-worldline-faithful` を使用し、新rendererは作らない。

v9.1ではこの方針を維持し、学習教師だけを改善する。Open JTalk整列失敗を許容せず、WORLDのオクターブ誤推定を補正し、平滑化したlog-F0残差を学習する。v9.1の学習済みモデルを評価するまでは、v10へアーキテクチャを拡張しない。

## v8から引き継がない問題

- 語彙アクセント、句の下降、句末上昇、話者の揺らぎを一つの10ms出力へ混在させていた。
- 現行v8学習結果はOpen JTalk整列率が約68.6%で、データの約31%を除外している。
- 学習コーパスに疑問文がなく、疑問上昇を学習できない。
- ±250centの教師クリップと、推論時の強度・p99・最大値制限に形状の維持を依存している。
- フレーム単位MAEだけでは、アクセント核の位置・核後下降・句末境界・急な曲率を評価できない。

## v9の構成

入力文をOpen JTalkで解析し、アクセント句ごとに次の基準を作る。

1. アクセント高低
2. アクセント核の位置
3. 句内の下降
4. 句末境界

v9は各アクセント句について、基準曲線への4つの補正アンカーを予測する。

- 句頭補正
- 核付近補正
- 句末補正
- 疑問・境界上昇補正

アンカーは句内の正規化位置で滑らかに補間し、フレーム曲線へ展開する。これにより、学習対象を予測可能な低次元制御へ限定し、母音内部の不規則なF0揺れを直接再生しない。

## 教師信号

- WORLD F0を使用する。
- オクターブ誤りと信頼度の低い値を除外する。
- 短い無声区間だけを補間し、log-F0を30〜50ms平滑化する。
- 発話ごとの中央値で基準化する。
- Open JTalk基準曲線との差分を補正教師にする。
- 学習時に±250centへハードクリップしない。外れ値処理と推論時の安全制限を分離する。

## 学習と評価

学習データでは、Open JTalkとのモーラ整列を改善し、除外率を記録する。疑問文、句末、読点、長母音、無声子音を含む評価セットを別に固定する。

評価指標はフレームMAEだけにしない。

- アクセント核の高低差
- 核後下降の方向と大きさ
- 句末上昇の再現率
- 曲線の傾き・曲率のp95
- 安全制限への到達率
- waveform基準に対する歯抜け・音質劣化
- faithful rendererでの聴感AB

v9は、v8よりMAEが少し良いだけでは採用しない。アクセント構造が改善し、ケロケロ・ガラガラ感と歯抜け感を増やさないことを合格条件とする。

## 実装順

1. v8の評価指標と固定比較条件を保存する。
2. Open JTalk基準曲線とアンカー教師を生成する。
3. `phrase_pitch`形式のv9 JSONとGo推論を追加する。
4. Python学習スクリプトでアンカー補正モデルを学習する。
5. 既存faithful rendererへ同じ`PitchCurve`として渡す。
6. 小規模データで構造指標を通過させてから全量学習する。

既存v8、v7、standard accentモデルの読み込みは維持する。JSONの`mode`でv9を識別し、既存のstandard accent versionとの衝突を避ける。
